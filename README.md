# Colorschemes

**Color reference:** actively maintained colorschemes (Dracula, Gruvbox, Catppuccin, Rosé Pine, Kanagawa, OneDark, Tokyo Night) with copyable hex codes.

Open the page: https://od728.github.io/Colorschemes/

- `index.html` – self-contained page (open locally or via GitHub Pages)
- `palettes.json` – raw color data per theme and variant

Status as of 2026-11-21; "last commit" only approximates "still maintained".
